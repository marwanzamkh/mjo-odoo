MJO — your store's AI marketing manager

Connect Odoo in two minutes. MJO reads; you approve.

MJO reads your posted invoices, products and stock from Odoo, then prepares offers that keep your margin, ready designs, and WhatsApp campaigns. Nothing is published, sent or priced before you approve it inside MJO.

What this module adds

  • «MJO read access» group — read-only rights on invoices, products, customers and stock. No create, no write, no delete.
  • MJO menu (administrators only) — opens MJO's connection form with your Odoo address and database name filled in. No password or key leaves Odoo.

How to connect

  1. Settings → Users → New: name «MJO», tick MJO read access only.
  2. Sign in as that user → My Profile → Account Security → New API Key. Copy it.
  3. Open the MJO menu, sign in to MJO (free trial at app.mjo.marketing), paste the user's login and the key, press «Test connection».

The module sends no data by itself and makes no outside calls. MJO connects with the standard Odoo external API using the user you created; delete that user or its key to stop access at once.
