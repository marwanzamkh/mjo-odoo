MJO — your store's AI marketing manager

Connect Odoo in two minutes. MJO reads; you approve.

MJO reads your posted invoices, products and stock from Odoo, then prepares offers that keep your margin, ready designs, and WhatsApp campaigns. Nothing is published, sent or priced before you approve it inside MJO.

What this module adds

  • «MJO read access» group — read-only rights on invoices, products, customers and stock. No create, no write, no delete.
  • MJO menu (administrators only) — one button that connects this database to MJO.

How to connect: one click

  1. Open the MJO menu and press Connect now.
  2. The module creates a user «MJO Connector» that belongs to MJO read access only, generates an API key for it and hands the key to MJO from your Odoo server over HTTPS. The key is never placed in a link.
  3. Sign in to MJO (free trial at app.mjo.marketing) and press «Connect Odoo now». MJO tests the connection and reads your products and customers.

On Odoo Enterprise the new internal user counts towards your subscription's users. Prefer to do it yourself? The same page has «connect manually»: create your own user with MJO read access, make an API key for it and paste both in MJO.

What leaves your Odoo

Only when an administrator presses Connect now: one HTTPS request to app.mjo.marketing with this database's address, its name, the connector user's login and its API key. Nothing else is sent by the module. After that MJO reads through the standard Odoo external API as that read-only user. To stop access at once, archive the user «MJO Connector» or delete its key; pressing Connect now again replaces the key.
